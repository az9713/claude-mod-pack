1. What a mod is

A mod is a plugin made of JavaScript or TypeScript event handlers. Claude Code calls a handler when an event happens, such as a tool call, a finished turn, or the moment the interface is drawn. The handler can watch the event, change it, or take it over. Mods need Claude Code v2.1.287 or later, run in Claude Code's own process, and need no Node.js, bundler or build step. The docs call the handlers "hooks", and call the older shell-command kind "settings hooks".

A mod differs from the other extension types in one way that matters for ideas: a mod can draw in the interface. A settings hook cannot draw, a skill cannot draw, and an MCP server cannot draw. That is why almost every mod below is something you can see: a band above the prompt, a pane beside the transcript, a spinner suffix, a toast.

How a mod loads

A mod is a folder with .claude-plugin/plugin.json, hooks/hooks.json (one key, modules, with one path), and the code file that exports register(on, options). Run claude --plugin-dir ./my-mod to load it for one session. Claude Code watches that folder and reloads the module on every save, so module variables reset and register runs again. Install from a marketplace with claude plugin install name@marketplace, then /reload-plugins. Mods that Claude writes inside a session go to ~/.claude/dev-mods/<session-id>/ after you answer the hot-reload question; copy one out to keep it.

Limits, costs and security that shape what we can build

Cost

Hooks cost no usage. A mod spends usage only when it calls a model ($.model.complete or $.model.fork) or submits a prompt. A fork shares the prompt cache. Text that a hook changes between requests can invalidate the cache.

Time

Each hook has 10 seconds, not counting time inside next or a $ call. A timed-out hook is skipped, so a guard fails open unless it has a .catch handler. Redraws are throttled to 10 a second (30 for the visible terminal pane), so nothing animates faster.

Surfaces

Mods draw in the terminal and the desktop app Code tab. The VS Code chat panel, claude -p and mobile run hooks but draw nothing. A pane that opens without the person asking needs 144 terminal columns.

Security

"A mod is code that runs with your permissions" and is not sandboxed. It can read files, start processes, make network requests, read env vars, see every prompt, approve tool calls, and spend usage. Run claude plugin validate <mod> before installing someone else's: it lists the $ calls the mod makes.

2. Mods in the Claude docs and blog

The three pages are the overview, the create tutorial, and a blog post that the page shows as written by Addy Osmani on 2026-10-01. The blog text reached us through a summarising fetch tool, so treat its wording as a paraphrase until you read the page. Three official sample mods sit in anthropics/claude-code-playground under claude-code/mods, shared without support.

Built-in mods

Six ship inside Claude Code: cc-plugin-agents-md (loads AGENTS.md), cc-plugin-diff (the /diff pane), cc-plugin-plugin-authoring (the authoring skill), cc-plugin-sec-default (cannot be turned off), cc-plugin-telemetry, and cc-plugin-you-should-know. The last one is a side agent that watches while Claude works and shows a note above the prompt. It is off by default: /plugin enable cc-plugin-you-should-know@builtin.

Ideas the blog lists without code

A cost or rate-limit meter in the status line. Team conventions added on prompt.submit. A file-access map. A focus timer with toasts. Stack-specific tool.call guards.

3. The three hosts

None of the three transcripts states a video title or the host's name. The names below come from the folder names (chase, kashef, herk) and from sponsor lines, so they are inferences. None of the three shows a mod being built from the first keystroke; Kashef and Herk say so in your notes, and Chase shows only the docs tutorial code in your README.

What the three agree on

All three show a cache or context awareness mod with an action attached: Chase's cache clock with a compact button, Herk's Cache Keeper with handoff and clear buttons, and Kashef's auto-handoff at a threshold. Chase and Herk both run an audit prompt over your own session logs to pick mods. Chase and Herk both show next-steps suggestions. All three say the best mod is the one built for your own workflow.

The audit prompt (your version, from Chase's README)

Audit how I use Claude Code. Read my last 30 sessions in ~/.claude/projects/ (the .json transcripts, newest first). Look for: things I ask for over and over; things I check by hand (usage, cache, git state, which files changed); steps I always do before or after a certain kind of task. Then suggest 5 Claude Code mods that would fix those. For each one, give the name, the problem it solves (quote the session moment that shows it), the event it plugs into and whether it acts before, after or instead, what it shows on screen, and whether it costs any usage. Rank them by how much time they'd save me. Don't build anything yet.

Kashef's removal loop, from your notes: claude plugin uninstall "$mod@my-mods" --scope user for each mod name. The marketplace name my-mods appears only in your notes, not in the transcript.

5. Wow shortlist

This section is my judgment, not a finding from a source. I ranked by how fast the effect is visible, whether it reacts to what Claude is really doing, and whether it is cheap to build. "Cost" is the usage cost to run it, from the sources. The sketch names the events and slots from the docs. Where a pick comes from a found mod, the name is in brackets. Items marked IDEA have no matching mod in anything we read.

For fun

Live cartoon spinner

The spinner is replaced by a cartoon of what the agent is doing right now. [Anshu's post, claude-toons, clawd-cartoons]

Wow: the screen mirrors the work in real time.
Sketch: tool.call + ui.render on Spinner + $.model.complete for new scenes.
Cost: claude-toons reports 138 free pre-made scenes; new scenes cost 2 to 4 cents each, capped at one per minute.

Arcade that pauses when Claude finishes

Play Snake, Tetris or Doom while Claude works. The game freezes the moment the answer lands. [cc-arcade, claude-tetris]

Wow: a playable game inside the prompt area.
Sketch: ui.render on Pane or AbovePrompt, turn.start/turn.complete to pause, Client element for key input.
Cost: none reported.

Boss fight from failing tests

A failing test spawns a pixel boss with one hit point per failure; fixing tests defeats it. [boss-fight]

Wow: the test run becomes a visible fight.
Sketch: tool.call result parsing for test output + Pane drawing.
Cost: none reported.

Storytime narrator

A tiny 260K-parameter model runs locally and tells a short story about your work. The tool in use picks the hero; filenames become character names. [cc-storytime]

Wow: a story about your own repo, with no API call.
Sketch: tool.call events as story input, local model in the mod, text in the band.
Cost: none (runs locally).

Token Weather with sound (IDEA)

Our own token-weather plus thunder when the band changes from Showers to Storm. No sound mod was found in the sources, and the $.audio.play API exists.

Sketch: turn.complete compares band to the previous band, then $.audio.play({ asset }).
Cost: none.

For productivity

Auto-handoff at a threshold

When context reaches a set percentage (Kashef shows 85%), the mod writes a handoff and starts a fresh session by itself. Kashef calls it the most useful mod. [auto-handoff, cs-rotate]

Wow: context stops being something you manage.
Sketch: turn.complete or session.measure + $.session.usage() + $.session.compact() or $.session.send.
Cost: a handoff summary uses tokens when it runs.

Cache Keeper

A countdown of the prompt-cache window, the cost if it expires, and one-click compact, handoff, or clear-and-continue. A notice five minutes before the cache goes cold. [Chase's cache clock, Herk's Cache Keeper]

Wow: a cost you can act on before you pay it.
Sketch: $.clock.every + AbovePrompt with Button + $.ui.toast.
Check first: both hosts say the cache lasts one hour, but no source we read confirms it.

Prompt queue

/q text while Claude works stacks prompts in a reorderable list; they send one at a time. /q now injects one into the next tool call. [claude-queue]

Wow: you stop waiting to type your next thought.
Sketch: $.command.register, turn.complete, $.prompt.submit.

Collision guard

Before an Edit or Write, the mod checks whether another chat touched the file in the last 30 minutes, and asks you what to do. [Herk]

Wow: a warning that a person would miss.
Sketch: tool.call for Edit/Write/NotebookEdit + $.ui.ask + $.store for last-touch times.

Model router with flight recorder

Force sub-agents to a cheaper model, and a timeline that proves which model ran each step. Kashef shows both together. [model-router, flight-recorder]

Sketch: agent.spawn returns { model }; turn.step logs usage; /timeline command.

Goal meter

For /goal runs: the goal text, phase, minutes elapsed, a task checklist, and percent complete. [Herk]

Sketch: Pane + $.state; needs the task list from the session, which we have not checked.

Next-steps with real buttons

Already installed here. Press 1, 2 or 3 to fill the prompt. A variant could add one-click skills from your own list. [Thariq's next-steps]

For learning

"Wait, what?" retell

A band above the prompt retells Claude's last answer in plain words, kept out of the transcript and the model context. [cc-mod-waitwhat]

Sketch: turn.complete + $.model.complete + AbovePrompt.
Cost: one short model call per turn.

Aside: a side chat

A read-only pane where you ask about the session so far; a tool-less fork of the transcript answers. [aside]

Sketch: $.model.fork + Pane + Input.
Cost: a fork shares the prompt cache, so about one short reply.

Quiz on your own diff (IDEA for a mod)

After each turn, ask you one question about what Claude changed, answered by pressing a digit; track weak topics. We found this only as shell hooks and skills (learning-with-claude, claude-tutor, a teach skill), not as a mod. The nearest mod is claudelingo, a vocabulary quiz.

Sketch: turn.complete + $.model.complete + Select + $.store.

Agent narrator

Translates each tool call into plain English with a time-saved estimate. [agent-narrator]

Sketch: tool.call + ui.render on ToolUse.

Mindful breathing while you wait

Four breathing patterns animate above the prompt while Claude works, and vanish when the reply arrives. [Mindful Claude]

Cost: none reported.

For safety and review

Blast radius

Holds rm -rf, force push or git reset --hard, shows what would change, then Proceed or Cancel. The blog calls it "a safety net, not a permission system": aliases and scripts that call rm get past it. [official]

Replay theater

A /replay command that steps through Claude's last file edits one diff at a time. [official]

Recording mode

Masks emails and figures on screen while you record; Herk shows an edit that still lands on the real file. Check the mechanism first: Herk says "blur" and "placeholders" in different places. [Herk, secret-redactor]

6. Caveats and conflicts

  • Reload behaviour differs by source. Chase says to reload plugins, Kashef says to start a new session, and our session used hot reload tied to the session id. These may be different versions.
  • Cost is not zero for every mod. Kashef says mods "might" cost nothing. Hooks cost nothing; next-steps forks the session every turn, and any mod that calls a model spends usage.
  • Cache length is unconfirmed. Chase and Herk say one hour. No source we read checks it against the docs.
  • Desktop versus terminal. The docs say mods draw in both. The next-steps README says its suggestions draw in the terminal only. Elements Svg (desktop) and Raster/Image (terminal) are not shared.
  • Speech-to-text guesses. "Thoric" is read as Thariq, /tray is a guess for the output tray command, and "crimson garden" is unconfirmed.
  • Popularity numbers. The awesome-list shows star counts of 95,885 for cctop and 73,669 for ruflo-mods. We do not trust them and did not use them.
  • Several community mods send data out. claude-roulette, network and claude-who use a service. Run claude plugin validate before installing any of them.
  • Not read. The docs test and troubleshoot pages, and the source code of the three official sample mods.

7. Questions for you

  1. Which surface do you use most: the terminal, or the desktop app Code tab? It decides whether we use Raster and Image (terminal only) or Svg (desktop only).
  2. For "wow", which matters more: something that moves and reacts (cartoon spinner, boss fight, arcade), or something that saves money or time you can measure (Cache Keeper, auto-handoff, collision guard)?
  3. May a mod spend usage? A retell band or a quiz makes one short model call per turn. Zero-cost mods avoid that.
  4. Do you want sound? The $.audio API exists, and we found no sound mod, so this is open ground.
  5. Do you want one big "bundle" plugin with several mods, or one small mod per idea? Small ones are easier to turn off and to remove.
  6. Should I run the audit prompt over your last 30 sessions first, so the mods fit how you actually work?
